# Legacy notebooks

These are the two self-contained notebooks of the first version of the workflow
(as submitted with the first manuscript), kept unchanged for reference and
provenance:

- `Displacement_workflow_complete.ipynb`: displacement (polarization) mapping
- `Strain_map_python_routine.ipynb`: strain mapping, Methods 1 and 2

**They are superseded by the `polarmap` package.** Use the notebooks in
[`../examples`](../examples), which call the tested package instead of embedding
the code. The mapping from the functions in these notebooks to the package API
is listed in the documentation page
[*From the original notebooks to the package*](https://cosmin7225.github.io/python-workflow-for-polarization-and-strain-mapping/migration.html),
together with the behavioural fixes made since (see also `../CHANGELOG.md`).
