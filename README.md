# python-workflow-for-polarization-and-strain-mapping

This repository provides a reproducible workflow for extracting **atomic-scale polarization vectors** from high‑resolution STEM images (HAADF/ABF).
The analysis pipeline is implemented in **Jupyter notebooks** and uses open‑source scientific Python tools to detect atomic columns, construct sublattices, calculate atomic displacements, and reconstruct polarization vector fields.

The workflow is designed for atomic‑resolution studies of ferroelectric materials and can be adapted to different crystal structures by adjusting the atom detection parameters and polarization reconstruction model.

---

# Method Overview

The analysis pipeline follows these main steps:

1. Image input and calibration
2. Atomic column detection
3. Sublattice construction
4. Polarization reconstruction from atomic displacements
5. Visualization of polarization vector fields
6. Optional strain analysis and correlation

---

# Example Results

Typical outputs generated by the notebooks include:

- Atomic‑resolution polarization vector maps
- Polarization magnitude maps
- Polarization angle maps
- Statistical histograms of polarization distributions

These tools allow quantitative investigation of nanoscale polarization behavior in ferroelectric materials.
